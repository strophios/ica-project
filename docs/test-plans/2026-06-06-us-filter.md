# Human Test Plan — US/not-US Pre-Filter

*Last updated: 2026-06-10. Generated from the test-analyst's coverage validation at the close of Phases 1–7 (automated coverage: PASS, 30/30 automatable criteria; `uv run pytest -q` → 618 passed; `Rscript r/tests/run_tests.R` → 79 passed). The steps below are the operator-gated/manual portion.*

## Prerequisites

- Working directory: project root. Run everything via `uv run` (no venv activation).
- Green baseline: `uv run pytest -q` (618 passed) and `Rscript r/tests/run_tests.R` (79 passed). Re-run both before starting if the tree has changed.
- Derived data: `us_filter/ldc_labeled.parquet` (from `Rscript r/dateline/build_labels.R`). For the apply path: `api_corpus/{year}.parquet` (from `Rscript r/api_ingest/rds_to_parquet.R`).
- A trained, calibrated artifact triple (`*.weights.h5` + `*.config.json` + `*.calibration.json`) for any step past training.
- Cluster steps require Explorer access (`/projects/ahd`), `mixed_float16`.

## End-to-End: Pre-1986 transfer + escalation (AC3.3-decision, AC6.3-real)

The core research question this filter feeds. Blocked on the human-coded gold set.

1. Build/obtain the human-coded event-location gold set (seed template: `validation/coding_template.parquet`, 546 rows; schema: `src/validation/schema.py`).
2. Score the gold-set articles with the calibrated model; run `src/validation/slice_eval.py` → both-class P/R/F1 + `proxy_gap` (dateline-vs-event-location agreement via `alt_corpus_id`).
3. Run `src/validation/escalation.py` with in-distribution baseline F1 and transfer F1.
4. Expected: recorded `{escalate, rationale}`; escalate True iff `baseline_f1 - transfer_f1 > margin` (default 0.1). Record the gap and decision.

## End-to-End: Free heuristic audit (AC6.1-real, AC6.2-real) — runs now

1. `Rscript r/audit/api_ldc_join.R` → `us_filter/audit/api_ldc_matched.parquet`.
2. `uv run python -m src.validation.free_audit`.
3. Expected: heuristic error rate vs dateline-source labels only + `lead_similarity` figure, with the biased-by-joinability caveat (AC6.5). Reference values from the 2026-06-10 run: error 0.0206 (n=159,867), similarity 0.9142, 505,712 matched pairs.

## End-to-End: DoCA recall diagnostic (AC6.4-real)

1. Assemble a `doca_id`-bearing scored frame (score DoCA-matched LDC rows via `apply_us_model`, or join via gold-set `alt_corpus_id` — both producers documented in `src/validation/doca_recall.py`).
2. `doca_recall` at the chosen threshold (see `docs/notes/us-filter-threshold-recipe.md` for the recall-targeted threshold recipe).
3. Expected: `{recall, n}` over non-null `doca_id` rows + the topic-skew caveat. Interpret recall in light of the caveat.
